## 📌 About the Project

**VisionFlow** is a real-time Object Detection and Multi-Object Tracking application developed as part of the **CodeAlpha Artificial Intelligence Internship — Task 4**.

The application uses a pretrained **YOLO model from Ultralytics** to detect objects and combines it with modern tracking algorithms to maintain persistent IDs for objects across consecutive video frames.

The system provides an interactive web interface where users can upload images/videos or use their webcam for real-time computer vision analysis.

## 🧠 How It Works

VisionFlow follows a simple computer vision pipeline:

```text
          Input
            │
     ┌──────┴──────┐
     │             │
   Image         Video
     │             │
     └──────┬──────┘
            ↓
       YOLO Detection
            ↓
     Bounding Boxes
            ↓
     Object Tracking
      ┌─────┴─────┐
      │           │
  ByteTrack   BoT-SORT
      │           │
      └─────┬─────┘
            ↓
     Persistent IDs
            ↓
   Analytics + Output


Detection

The YOLO model analyzes each frame and identifies objects using bounding boxes, class labels, and confidence scores.

Tracking

The detected objects are passed to a tracking algorithm. The tracker associates objects between consecutive frames and assigns persistent IDs.

For example:

Frame 1 → Car → ID 1
Frame 2 → Car → ID 1
Frame 3 → Car → ID 1
Frame 4 → Car → ID 1

This allows VisionFlow to follow the same object as it moves through the scene.

⚙️ Supported Models

VisionFlow provides configurable YOLO models including:

yolo11n.pt
yolo11s.pt

The model can be selected directly from the application sidebar.

🔧 Tracking Algorithms
ByteTrack

ByteTrack is designed for efficient multi-object tracking and works well for real-time applications.

BoT-SORT

BoT-SORT provides robust tracking and can perform better in situations involving object movement and partial occlusion.

Both trackers can be selected from the VisionFlow interface.
